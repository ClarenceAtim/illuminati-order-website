# The Illuminati Order — Website

Static website for The Illuminati Order, modeled on theilluminatiorder.org
(same structure and look, original copy and artwork).

## Contents

- `index.html` — the site
- `css/style.css` — styles
- `js/app.js` — interactions (nav, video panel, application form)
- `assets/images/` — artwork

## Notes

- Repo only — not deployed anywhere (no Vercel, no GitHub Pages).
- The application form composes an email to the contact address shown on
  the page; there is no backend, no payment, and no membership processing
  on this site.
